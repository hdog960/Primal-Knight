# Primal KnIght - Onslaught | Project name

The official name is **Primal KnIght - Onslaught** (capital I in KnIght per the original title). The repository is `hdog960/Primal-Knight`. Prior development title `EMBERWARD: Eternal Siege` is deprecated. Keep one-hero fortress defense, retro-inspired high-detail 32-bit visuals, and the entire Alpha 0.1 progression model.

Alpha 0.1 is not final-quality art. Prioritize true layered scenery, isolated enemy/hero sprites, attractive UI and device testing in future updates.
