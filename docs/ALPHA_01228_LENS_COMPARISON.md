# Alpha 0.12.28 — Original vs Tactical Lens Review

## User-facing implementation
From the active siege **FPS** panel or Settings, select **COMPARE LENS PNG**. The game renders its **real existing 960×540 painted battlefield canvas** once with LENS off and once with LENS on, without advancing a simulation frame. It composites both images into one 1920×624 PNG with prominent ORIGINAL and TACTICAL CONTRAST headings and the actual tier/wave printed in the header.

The two halves use the same live enemy positions, HP, weather timestamp, boss staging, native patrol, fortress and projectile effects. Only the temporary LENS presentation differs. Camera shake is set to zero for **both** captured halves to make visual alignment fair, then restored to the original current strength. A `finally` block restores both the user’s original LENS selection and on-screen canvas even on an error; no `setClarityLens` call writes a visual preference.

PNG sharing follows the established local battlefield art export: generate binary synchronously during the user tap, try native iOS Share Sheet with a File, safely fall back to local download if unsupported, and respect dismissed Share Sheets without surprise files. No outgoing network requests, analytics, saved screenshots or personal data are generated by the game.

## Verifications and roadmap
The new `tests/lens-comparison.js` executes the real game in a Node VM with a fake canvas. It verifies exactly two composited 960×540 frames, original-first and lens-second even when the lens starts ON, the correct on/off wash, accurate labels, original lens/shake restore, no progressed waves or character mutation, Settings and FPS action wiring, native share, cancellation and unsupported fallback. Full release gate: **53 required checks including JavaScript syntax**.

This is an image-comparison tool for physical-iPhone acceptance, **not** evidence of an actual iPhone test. Player review still needs crowded waves in portrait and landscape, Share Sheet and local file confirmation, and at least one 30-minute active siege with battery/heat observations. Alpha 0.12 remains open; locked Alpha 0.13–0.15 and original ~1,250-hour design target are unchanged.
