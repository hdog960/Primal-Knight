# Alpha 0.15.21 — Battle Plan Field Ledger

This development slice adds an actual player-facing, collapsible **Battle Plan Field Ledger** beneath Battle Plans in the Battle lobby. When a real siege starts, a true four-way match of unlocked doctrine, passive, automatic-cast timing and targeting focus is captured. No battle strategy is inferred from an older record, custom combination or altered setting. Only the existing bounded 24-record original character siege archive receives the optional `battlePlan` value.

For up to four measured, recently fought same-territory sorties, show the exact plan, starting wave, last reached wave, number of original-engine waves actually cleared, last truly cleared wave (not arrival), unique first clears, real fortress breaches, and measured breach/Sapper HP. Differences in prior purchases, waystones, seeds and enemies are not controlled. No predictor, free item, extra currency, rank, tier, cooldown, HP, damage or new top-level character schema.
